# وب‌سایت بنیان فولاد داریا

وب‌سایت فارسی و راست‌به‌چپ «بنیان فولاد داریا / Bonyan Foulad Daria». پروژه یک
سایت استاتیک React است که با Vite ساخته و خروجی آن برای انتشار در Cloudflare
Pages آماده می‌شود. تنظیم قدیمی GitHub Pages دیگر مسیر انتشار سایت نیست.

## اجرای محلی

نیازمندی: Node.js 22.13 یا جدیدتر.

```bash
npm ci
npm run dev
```

## کنترل کیفیت

فرمان زیر lint، بررسی TypeScript، تست‌های منطق و قرارداد محتوا، build تولید و
تست خروجی نهایی را اجرا می‌کند:

```bash
npm run verify
```

GitHub Actions همین فرمان را برای کنترل کیفیت اجرا می‌کند. انتشار Cloudflare
Pages مستقل از این گردش کار است.

## قیمت‌های روز

قیمت میلگرد، تیرآهن، ورق، پروفیل، لوله، نبشی، ناودانی و محصولات مفتولی
به‌صورت زمان‌بندی‌شده دریافت و منتشر می‌شود، اما GitHub هرگز چیزی commit یا
push نمی‌کند. دو بخش این کار را انجام می‌دهند:

- **گردش‌کار GitHub Actions «Refresh prices (Cloudflare relay)»**
  (`.github/workflows/price-refresh.yml`) طبق زمان‌بندی، داده را از منبع
  بازار دریافت و از نظر ساختار و سازگاری معنایی اعتبارسنجی می‌کند، سپس با
  یک درخواست POST به یک Cloudflare Worker جداگانه می‌فرستد. این workflow نه
  به `app/data` دسترسی می‌نویسد، نه دستور git دارد، و مجوز نوشتن روی مخزن
  هم ندارد؛ **Cloudflare شبکه‌اش اصلاً نمی‌تواند به منبع قیمت (fooladiranian.com)
  متصل شود، به همین دلیل دریافت داده روی GitHub Actions انجام می‌شود**، نه
  خود Worker.
- **Cloudflare Worker** (`workers/price-refresh`، پروژه‌ی
  `foulad-price-refresh`) داده‌ی دریافتی را دوباره (مستقل از GitHub)
  اعتبارسنجی می‌کند و فقط در صورت موفقیت هر سه دیتاست، آن‌ها را در
  Cloudflare KV ذخیره و بازسازی سایت را در Cloudflare Pages فعال می‌کند.

دریافت ناقص یا نامعتبر (چه در GitHub Actions، چه در Worker) با خطا متوقف
می‌شود و آخرین نسخه‌ی معتبر ذخیره‌شده بدون تغییر باقی می‌ماند.

هر build (چه در Cloudflare Pages و چه محلی) با `npm run prices:pull`
آخرین نسخه‌ی معتبر را از همان Worker می‌گیرد و جای فایل‌های
`app/data/*.json` موجود در مخزن را عوض می‌کند؛ اگر متغیر محیطی
`PRICE_DATA_ENDPOINT` تنظیم نشده باشد یا دریافت شکست بخورد، همان نسخه‌ی
موجود در مخزن (fallback) بدون خطا مصرف می‌شود. فایل‌های `app/data/*.json`
در مخزن فقط یک نسخه‌ی پیش‌فرض/fallback هستند، نه منبع بروزرسانی خودکار.

برای اجرای دستی همان گردش‌کار زمان‌بندی‌شده (دریافت، اعتبارسنجی و ارسال به
Cloudflare) در محیط محلی:

```bash
PRICE_DATA_ENDPOINT=... PRICE_INGEST_TOKEN=... npm run prices:refresh-and-publish
```

برای اجرای دستی بروزرسانی محلیِ فایل‌های fallback در `app/data`:

```bash
npm run prices:update
```

برای اعتبارسنجی داده موجود بدون دسترسی شبکه:

```bash
npm run prices:validate
```

## ارتباط فروش

این وب‌سایت فروشگاه اینترنتی نیست. فرم پیش‌فاکتور و فرم شکایت در وضعیت فعلی
فقط متن درخواست را داخل مرورگر آماده می‌کنند و اطلاعات را به سرور
نمی‌فرستند. ثبت نهایی از طریق شماره‌های رسمی انجام می‌شود. پس از اعلام ایمیل
رسمی یا اتصال به سامانه مورد تأیید، مسیر دریافت نهایی باید در تنظیمات مرکزی
تکمیل شود.

## پیش‌بارگذار

پیش‌بارگذار سبک حداکثر یک‌بار در هر نشست مرورگر و حداکثر برای ۱٫۲ ثانیه نمایش
داده می‌شود، دکمه عبور دارد، کاهش حرکت سیستم‌عامل را رعایت می‌کند و در هر خطای
اسکریپت، صفحه اصلی به‌صورت پیش‌فرض قابل مشاهده می‌ماند.
